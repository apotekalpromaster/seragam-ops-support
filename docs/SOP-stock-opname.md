# SOP — Stock Opname

**Siapa:** Staf menghitung & mengisi; Admin menyetujui.

1. **Stock Opname** → **Buat lembar opname** (pilih tanggal hitung). Opname pertama membentuk saldo awal (OPENING).
2. Hitung fisik per SKU di gudang. Isi qty langsung di layar (tersimpan otomatis) **atau** *Unduh lembar hitung*,
   isi kolom `qty_fisik` di Excel, lalu *Upload hasil hitung*.
3. Opname berkala: setiap baris dengan selisih wajib diberi **alasan**.
4. **Ajukan untuk approval.** Qty terkunci.
5. Admin memeriksa selisih → **Setujui** (ketik SETUJU) — sistem membuat transaksi penyesuaian (ADJ) otomatis —
   atau **Kembalikan ke draft** bila perlu dihitung ulang.

Stok tidak pernah diketik langsung. Kesalahan setelah disetujui dikoreksi admin lewat **Stok → Riwayat transaksi → Koreksi**.
